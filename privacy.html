Privacy Policy

Last updated: October 2026

What the app is

Invoice Flow is a private tool used only by its owner. It runs on the owner's own computer and is not a hosted service.

Google data the app accesses

  • Google Drive: uploads PDF files (timesheets and invoices) into folders the owner chooses, and checks those folders for an existing file with the same name so it can be replaced instead of duplicated.
  • Gmail: sends billing emails on the owner's behalf. The app does not read, search or delete email.

How the data is stored and shared

Access tokens are stored only on the owner's computer. No Google user data is sent to any server operated by the app, sold, shared with third parties, or used for advertising or to train AI models.

Limited Use

Invoice Flow's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
